# 00｜專案背景、範圍與版本基準

## 1. 專案目的

HighwaySwapSim 用於高速公路 A、B 兩側服務區的充換電站方案評估。使用者可設定供電設備、效率、車流與電池條件，再以受限模擬檢視交付能力、排隊、能源損耗及規劃收益。系統讓設備設計、逐時服務與年度估算使用可追溯的同一份輸入，而不是各自維護一張無法核對的試算表。

目前回答的工程問題包括：既定一期設備能供應多少需求、瓶頸出現在哪個支路、外槍與電池回充互斥如何影響庫存，以及相同 DC 交付量下使用 SST 相對箱變＋PCS 可節省多少購電。

## 3. 現行一期設備配置

| 設備／條件 | A 區 | B 區 | 定義 |
|---|---:|---:|---|
| 電網接入 | 6000 kVA | 2500 kVA | kVA 不是可交付 kW |
| SST | 1×1680 kW | 1×1680 kW | 兩側 SST 的上游都由 A 區供電 |
| 箱式變壓器 | 2500 kVA | 2500 kVA | 各自供本側 AC/DC 與站用負載 |
| AC/DC | 3×560 kW | 3×560 kW | DC 輸出額定；整機效率 95.35% 可逐台調 |
| DC/DC | 5×560 kW | 5×560 kW | 公共 DC 母線下游；不另增加電源能力 |
| 電池倉 | 8 倉 | 8 倉 | 倉 1–3 為 AC 組，4–8 為 DC 組 |
| 外槍終端 | 3 座／6 槍 | 3 座／6 槍 | AC 組 1 座、DC 組 2 座；雙槍終端 |
| 電池額定容量 | 513 kWh | 513 kWh | 共用 SOC 預設 20%→100%；可調 |
| 換電工位 | 1 工位 | 1 工位 | 7.5 分鐘／次為運營假設 |

母線 1＋2 合併為同一公共 DC 母線，不模擬開關動作。兩側可互相支援，但總 SST 輸出最多 3360 kW，單側跨區支援還受該側剩餘能力限制。每側 AC 組、DC 組各自整組互斥：供外槍時該組暫停電池回充。調度為外槍優先，再供站用與回充，不預留最低功率；必要站用不足仍可能使相依設備停機。

## 4. 範圍分界

| 層級 | 本期涵蓋 | 不得擴大解讀 |
|---|---|---|
| 電氣容量 | 額定、效率、上游共享與路徑可達性 | 不是並聯穩定性或短路保護設計 |
| 營運 | 逐時需求展開、排隊、電池與外槍服務 | 不是實際道路微觀交通模型 |
| 電池 | SOC／SOH、可選能量曲線與功率分段 | 預設值不是實測 BMS 特性；十年無自動老化 |
| 年度 | 六組三日案例折算、庫存扣除、背景用電 | 不是十年連續事件模擬或穩態排隊證明 |
| 效率收益 | 同量 DC 供應下 SST 與箱變＋PCS 的電費差 | 不是完整净利、投資回收或替代 PCS 容量驗收 |
| 完整模型選配 | 程式可設定線損、PV、ESS、備援等 | 一期預設未啟用者不得計入一期成果 |
| 軟體驗證 | 固定案例、獨立預期、Worker、DOM、匯出 | 不等於現場校準、原生瀏覽器或資安認證 |

## 6. 名詞與量測邊界

| 名詞 | 本文件定義 |
|---|---|
| REQ／TC／SOP | 需求編號／測試案例編號／操作程序編號 |
| kVA／kW／kWh | 視在功率／有效功率／積分電量；不可互換 |
| AC／DC 需求分流 | 箱變→AC/DC 支路／SST→DC/DC 支路；兩者都可向車端輸出 DC |
| 需求／交付／未交付 | 客戶輸入需求／實際完成服務電量／期末仍未交付；不以額定容量替代實績 |
| 回充電量／售電量 | 站內電池吸收電量／交付客戶的淨電量；含庫存變化時不相等 |
| 草稿／專案／結果 | 未套用編輯／目前已套用輸入／上次成功運行及參數快照 |
| 410 與 410.4 kWh | 來源每次需求 410；513×(100%−20%)=410.4；非電池容量改成 410 |
| CNY／萬元 | 人民幣元／一萬元；本期效率圖以萬元 CNY 顯示 |
