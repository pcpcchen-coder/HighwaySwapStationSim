# HighwaySwapSim 操作手冊

## 0. v0.6 完整模型的新增操作

上方「完整物理案例」載入含 `detailed.version=1` 的新案例；受限模式使用 v0.6.0 引擎。未含 `detailed` 的歷史 JSON／XLSX 匯入後保留原 v0.5.0 計算語義，不自動轉成新預設。完整元件與參數路徑見 [完整模型手冊](COMPLETE_MODEL_GUIDE.md)。

1. **先保存與決定天數。** 匯出目前專案 JSON，設定期別、天數、站務容量及 SOC，再填詳細設定。
2. **編輯完整模型草稿。** 在「完整模型設定」選分區、搜尋參數。空集合可用「新增待填項目」建立第一筆，曲線亦可產生待填點，再用參數表編輯；沒有快捷範本的結構仍可使用 JSON 編輯器。時間／ID／選項只是可改的操作初值，未知容量、效率、價格等不代填。
3. **填完後套用。** 只改既有曲線、負載或成本按「套用設定」；新增設備端口或改共享連接時按「套用並重建設備連接」。重建會取代手動連線、座標與單台額定，應先完成再做供電設計微調。
4. **檢查供電設計，再編輯事件／價格。** 核對每個模型 ID 及端口存在、供電路徑與限額。逐時表生成的重卡事件與完整模型的精確事件會相加；完全使用逐車事件時關閉 `useHourlyTruckDemand`，避免重複計車。改事件後亦須套用完整模型草稿。
5. **確認缺值清單並執行測算。** 啟用的物理模組缺必要值時不能計算；未啟用的模組不參與結果。財務尚未填齊可先做物理測算，但不提供缺少依據的利潤結論。
6. **確認成功快照後驗算。** 瞬時模式檢查當下端口 kW，區間累計模式可輸入子分鐘起訖。新增全站摘要會消除 ESS／UPS 回充與放電的內部移轉，另列自放電、容量衰減溢出、儲能庫存及營運交付。
7. **檢查財務後匯出。** 上方 JSON 保存目前已套用專案；本頁草稿 JSON／CSV 另存 `detailed`；結果 XLSX 保存上次成功快照及帳本。修改任何會影響結果的資料後必須重算，才可把 XLSX 當成新方案結果。

「新增待填項目」及結構檢核更新的是本頁草稿，尚須按「套用設定」才更新專案。曲線與物理附加模組可先停用再保存待填資料；沒有啟用開關的負載、事件、施工排程等，新增後若缺必要值會阻擋執行。施工列的 `enabled=false` 是指定時刻關閉設備，不是停用這筆排程。

### v0.6 累計窗口與離散事件

連續功率採 `[起點,終點)` 積分；儲能期初／期末採事件調整後庫存，容量衰減造成的離散溢出損失採 `(起點,終點]`，歸入前一段。任意相鄰窗口的電量、被動損耗與庫存變化仍可相加；起訖相同為零。

自放電依保存的區間初始庫存與係數求連續解，不能把整段平均自放電率直接套到子分鐘區間。容量溢出是 kWh 事件，當下模式也保留 kWh，不除以步長冒充 kW。換電完成採 `[起點,終點)`；恰在模擬期末完成者另歸最後關帳區間。核對時請查看畫面揭露的端點政策。

沒有已保存的儲能／服務時間資料時顯示未計算，需重算；不以零取代。沿線節點帳、全站外部帳與換電營運帳是不同邊界，不能再次相加。操作及公式詳見 [完整模型手冊第 6 節](COMPLETE_MODEL_GUIDE.md#6-瞬時與累計驗算)。

### 設定與結果的三個層次

| 資料 | 保存／更新方式 | 生效時機 |
|---|---|---|
| 完整模型頁未套用草稿 | 本頁「匯出本頁草稿 JSON／CSV」 | 按「套用設定」才寫入目前專案 |
| 目前已套用完整專案 | 上方「JSON」 | 重新測算成功後進入結果快照 |
| 最後成功 `parameterSnapshot` 與結果 | 能量流數值 JSON／結果 XLSX | 編輯、讀檔或測算失敗都不修改原成功快照 |

完整模型 JSON／CSV 匯入只取代 `detailed`，不取代根拓撲與逐時表；新增端口仍須重建。結果 XLSX 追加詳細設定、服務、電池／儲能、電氣讀數、PV／外售／切換、月帳單、存貨估值、生命周期與財務缺項表；匯入仍以 `Project_JSON` 還原設計，不從 Excel 任意展示表反推設定，也不直接恢复運行狀態。

## 1. 先分清楚目前設計與測算結果

系統同時保留「目前編輯中的設計」及「上一次成功測算的快照」。修改設計不會自動重算，也不會讓舊結果自動變成新設計的結果。

| 畫面／按鈕 | 使用哪份資料 | 修改後何時更新 |
|---|---|---|
| 供電設計、站務配置、逐時案例等編輯欄位 | 目前編輯中的設計與參數 | 修改立即生效於編輯資料 |
| 逐時案例「匯出需求 CSV／JSON」 | 目前編輯中的全部逐日需求及價格 | 不必先測算；不包含供電與站務設定 |
| 供電設計「整套設備 JSON／設備參數 CSV」 | 目前編輯中的設備設定 | 不必先測算；詳見設備設定文件 |
| 頁面上方「JSON」 | 目前編輯中的完整專案 | 可立即匯出，不必先測算 |
| 能量流驗算、模擬結果、結果相關財務輸出 | 上一次成功測算的快照 | 重新測算成功後更新 |
| 頁面上方「結果 XLSX」 | 上一次成功測算的設計與結果 | 重新測算成功後才包含新修改 |
| 能量流內「匯出全圖數值 JSON」 | 上一次成功測算中，目前選定時刻或區間的全圖數值 | 依該次結果及所選時間匯出 |

出現「參數已變更」或「結果圖表與 XLSX 顯示上次測算快照；JSON 匯出目前參數」時，代表畫面上的結果尚未套用目前修改。

## 2. 修改既有設計並取得新結果

1. **先選定起始案例或匯入專案。** 要延續自己的設計，按上方「匯入」，選擇先前保存的專案JSON或本系統匯出的XLSX。第一次操作也可先選預設案例。
2. **先設定案例名稱、供電方案、連續天數、站務與設備配置。** 完整設備案例中，修改「站務配置」中 SOC 以外的欄位，或「設備與容量」中的工程配置／負載假設／CATL配置欄位，會自動重建拓撲；切換一期／二期也會重建。縮短天數會移除超出範圍的需求列及停機排程，延長則以第一天需求複製新增日，因此先決定天數，再編輯逐日需求與排程。
3. **完成配置後，最後再到「供電設計」手動修改設備參數、啟停狀態及連線。** 先確認逐時需求、效率及財務設定，再作最後的自訂拓撲檢查。若回頭修改會重建拓撲的欄位，必須重新檢查／套回自訂連線、額定值與位置。只移動圖面座標不會改變電氣容量或效率，但保存的設計仍會包含新座標。
   逐時需求可在「逐時案例」直接修改，或透過該頁專用 CSV／JSON 匯入。需求變更不重建供電設計；先設定天數再細修需求。完整欄位與步驟見 [逐時需求操作](SERVICE_PROFILE.md)。
4. **先按頁面上方「JSON」保存目前設計。** 此步不需要先完成測算；即使尚有參數待修正，也可先備份編輯資料。重新匯入時仍需通過專案格式與參數檢查。
5. **開啟「能量流驗算」，按「執行目前受限參數」。** 此按鈕使用目前修改過的專案並切換至受限營運模擬。也可在上方選「受限營運模擬」後按「執行測算」。
6. **等待測算成功完成。** 確認出現「測算已完成，結果與參數快照已更新。」且狀態為「快照已同步」。如果期間又修改參數，結果可能再次變成舊快照，需重跑。
7. **檢查新結果與診斷。** 能量流圖應顯示新設計的設備及連線，再檢查功率限制、未交付需求、停機或輔助供電不足、期末庫存等。成功完成計算不代表每筆需求都已交付，也不等同獲利已獲保證。
8. **驗算後再按「結果 XLSX」。** 這時檔案保存新設計及其對應結果；也建議再存一份上方JSON，保留本次受限模式與最後確認的參數。若之後再修改任何參數，請重新執行第5–8步。

**測算失敗或中途停止時，系統保留上一次成功的結果。** 請修正錯誤並重新執行；不要把仍顯示的舊圖表或匯出的舊XLSX當成新設計成果。

## 3. 能量流驗算的操作順序

1. 先依第2節完成受限測算。來源原表重播沒有實體節點功率記錄，無法用來做當下功率或任意區間累計驗算。
2. 在「圖面數值」選擇所需模式：

| 模式 | 時間操作 | 顯示內容 |
|---|---|---|
| 當下功率 kW | 拖時間軸、輸入精確分鐘，或跳至前後變化時刻 | 該時刻所在模擬區間的功率 |
| 每小時電量 kWh | 選擇該小時內的時刻 | 整個小時的累積電量 |
| 區間累計 kWh | 拖動左端起點與右端終點，或輸入起訖分鐘 | 所選區間的總輸入、總輸出、總損耗 |

3. 累計模式可按「期初至目前」將起點歸零，或按「完整期間」查看全部模擬時間。區間以起點包含、終點不包含計算；起訖相同則電量為0。分鐘從模擬期初開始，D1代表第一天。
4. 全圖查看結構，放大或搜尋名稱／ID定位元件。點選節點，核對輸入＝輸出＋損耗、出線合計與末端吸收；點側欄相鄰元件可沿連線追查。
5. 需要保存當下或區間的逐節點讀數，按「匯出全圖數值 JSON」。它會保存所選模式、起訖／時刻、單位、全部節點和連線數值及參數快照。

拖時間軸與切換模式只是在查閱**同一次測算**的記錄，不會重新模擬或套用尚未測算的設計修改。累計總輸出採末端吸收量，包含電池回充、直充與輔助用電；不加總所有串接設備輸出，也不等同換電銷售電量。

詳細單位、守恆公式與驗證範圍見 [能量流驗算說明](ENERGY_FLOW_UI.md)。

## 4. 保存最新修改：JSON與XLSX的順序

| 目前情況 | 建議操作 | 保存結果 |
|---|---|---|
| 剛修改設計，尚未重算，想先備份 | 按上方「JSON」 | 最新編輯中的設計 |
| 修改後立刻按「結果 XLSX」 | 此時仍會匯出舊結果；請先重新測算 | 上一次測算的舊設計與結果 |
| 新設計已重新測算成功，快照已同步 | 按「結果 XLSX」；也可另存專案JSON | 新設計與對應結果 |
| 測算報錯、停止，或完成後又修改參數 | JSON先保存修改；修正／重新測算成功後再匯出XLSX | 避免把舊結果誤認為新結果 |
| 要保存能量流中的特定時間區間讀數 | 先完成測算，再選區間，按「匯出全圖數值 JSON」 | 該次測算的區間驗算記錄 |

XLSX包含設備參數、啟停狀態、圖面座標、連線、設備排程及完整專案資料，也附逐時結果、交易、元件／連線電量、來源電表與財務設定。它保存的是**當時的完整設計快照**，不包含逐次修改的前後值或修改時間。

XLSX不是完整的執行狀態備份，也不包含可直接還原能量流時間軸的全部逐事件功率記錄。建議將不同設計的檔案另存名稱，例如 `方案A_修改前.json`、`方案A_修改後.json`、`方案A_驗算完成.xlsx`；瀏覽器可能對同名下載自動加序號，請自行確認檔名。

## 5. 日後匯入並繼續操作

1. 若頁面已有未保存修改，先按上方「JSON」備份。
2. 按上方「匯入」，選擇專案JSON或先前由本系統匯出的原始XLSX。
3. 匯入只更新目前設計與參數，**不會自動執行測算，也不會直接還原舊的運算結果**。檢查匯入的設備、連線、站務設定與需求後，按「執行目前受限參數」。
4. 等待成功，再檢查能量流與結果，最後匯出新的XLSX。

XLSX匯入以檔案內的完整專案資料為準；Excel開啟後另存的格式不保證能匯入，請保留系統原始下載檔。直接在Excel修改`Equipment`、`Topology`或其他顯示表格，不代表修改會被匯回系統。設備請在工作台修改，或使用符合專案格式的JSON。逐時需求可在「逐時案例」匯出需求CSV，以Excel修改並另存CSV UTF-8後匯回；此格式專為需求修改提供。能量流的「全圖數值JSON」是驗算記錄，不能取代上方「JSON」作為專案匯入檔。

## 6. 示範案例與重建按鈕應在何時使用

| 按鈕／操作 | 行為 | 正確使用時機 |
|---|---|---|
| 「執行目前受限參數」 | 使用目前編輯的設計重新測算 | 驗算自己的修改 |
| 能量流內「完整設備案例 · 3 天」 | 載入預設完整設計與三天需求，取代目前專案後立即測算 | 從示範案例重新開始；已有修改請先匯出JSON |
| 上方「完整物理案例」 | 將目前專案換成完整物理預設；結果仍需重新測算 | 設定起始案例，應在細部編輯前使用 |
| 一期／二期、完整案例的站務配置（SOC套用除外）與工程配置欄位 | 修改時自動重建拓撲，可能覆蓋自訂連線、設備額定值及座標 | 在最後手動供電設計之前完成；回頭修改後需重新核對拓撲 |
| 「重建完整設備拓撲」或載入SST／PCS路徑 | 依目前配置／預設重建拓撲 | 確實要重建設備和連線時；先備份自訂設計 |

驗算自己剛修改的供電設計時，請按「執行目前受限參數」。不需要重新載入三天示範案例；否則會以預設案例取代自己的設計。

## 7. 一個容易核對的先後範例

1. 成功測算「方案A」：設計、能量流與XLSX都對應A。
2. 將一個供電參數改成「方案B」，尚未重算：上方JSON保存B，能量流與XLSX仍是A。
3. 成功重新測算B：能量流與XLSX才更新為B。
4. 匯入先前A的檔案：目前編輯恢復A，能量流仍是B；重新測算成功後，才再次顯示A的結果。

## 8. 匯出與報告前核對

- 情境名稱、供電設計、需求、連續天數與成本設定都是本次要報告的版本。
- 已成功完成受限測算，沒有仍待同步的「參數已變更」提示。
- 能量流圖使用該次設計；報告註明當下功率、小時電量或區間累計，以及所選時間範圍。
- 已檢查診斷、未交付需求與庫存缺口；數值守恆不直接等同真實場站獲利保證。
- 最新設計JSON、對應XLSX與必要的全圖數值JSON已下載，且檔名能區分方案。

目前沒有自動保存個人草稿、逐次修改歷程或永久保存本頁比較清單。離開、重新整理或匯入／載入另一個案例前，請先下載要保留的資料。

## 9. 修改到站事件與需求檔

先設定天數 →「逐時案例」選日期／服務區 → 修改車次與總kWh，或匯出需求CSV供Excel修改 → 選合併／全期取代後匯入 → 核對到站方式、種子、價格與SOC → 保存完整專案JSON → 重新受限測算 → 能量流驗算 → 結果XLSX。

需求檔保存全部天數兩區的需求與價格，使用day=1起算；不包含供電設計、到站方式、種子或計價模式。匯入沿用目前設定，不自動重算。詳細規則、範例與欄位見 [逐時需求編輯、匯入與匯出](SERVICE_PROFILE.md)。

## 10. 修改設備與單台效率

先完成期別、天數、站務與工程配置 → 最後修改供電設計中單台額定／連線 → 在設備組裝模式設定每台效率或沿用全域 → 匯出設備JSON／CSV或完整專案JSON備份 → 重新受限測算 → 能量流驗算 → 結果XLSX。

供電設計提供整套設備JSON取代及參數CSV合併。設備檔保留目前需求、價格、天數與財務；重建拓撲會移除個別覆寫，應在細部調整前執行。完整欄位、保存範圍與數值邊界見 [設備參數、效率與匯入匯出](EQUIPMENT_SETTINGS.md)。


## 11. 設定換電 SOC 範圍

1. 到「設備與容量」上方的「換電 SOC 設定」，或「站務配置」各站卡片。
2. A、B 站可分別輸入「回收 SOC 下限」與「交付 SOC 上限」，單位是百分比；有效範圍為 `0 ≤ 下限 < 上限 ≤ 100`。例如513 kWh電池設20%→80%，每次補電為307.8 kWh。
3. 檢查每次電量與全期電量預覽，再按「套用 A／B 區 SOC 並同步全期換電需求」。未按套用前只是在編輯輸入框，JSON與測算仍使用目前已套用值。離開此頁、匯入專案或修改該站其他參數前請先套用；未套用輸入會重設。
4. 套用只更新該站 SOC 與所有日期、所有小時的換電需求電量。保留車次、直接充電需求、價格、另一站、供電拓撲、自訂效率及停機排程；不重建設備。不會自動重跑測算。
5. 保存上方專案JSON → 重新執行受限測算 → 能量流驗算 → 匯出結果XLSX。舊結果與XLSX在重新測算前仍是舊SOC快照。

此SOC為同站換電電池的共用回收值與交付門檻；期初可用電池亦以交付上限初始化。尚不是每台車各自的SOC、單支充電槍的SOC曲線或充電效率。下限／上限都可改；0%→100%可用，空白、反向、相等或超範圍不可套用。

完整專案JSON與結果XLSX包含已套用SOC及對應需求；整套設備JSON也包含SOC，但設備匯入依原契約不改需求。匯入不同SOC設備設定後，即使輸入框數值未變，也可再按「套用」同步需求。需求CSV／JSON只保存電量與價格，不含站務SOC；需另存完整專案才能重現。

修改電池容量後，請再套用SOC重算需求。頂端「完整物理案例」始終表示重設到513 kWh、20%→100%的預設，不是目前已修改案例的電量讀數。詳細邊界與驗證見 [SOC設定說明](SOC_SETTINGS.md)。
