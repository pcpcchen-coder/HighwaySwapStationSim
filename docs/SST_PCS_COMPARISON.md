# 0.8.1 — SST 與替代 PCS 的效率收益比較

2026-09-19 使用者要求替換「累計能源後貢獻」圖，並先保留原版。還原資訊見 [RESTORE_BEFORE_SST_PCS_CHART.md](RESTORE_BEFORE_SST_PCS_CHART.md)。本文件對效率比较的定義優先於 SINGLE_BUS_PHASE1.md 的舊 AC/DC 基準說明。

## 畫面與操作

十年估算的第四張摘要卡與右側圖改為使用 SST 相較改用 PCS 的累計節省電費。柱狀為当年差額，折線為從起始年累計的差額，單位萬元 CNY。比較明細紧接圖表，逐年列出兩條路徑效率、相同 DC 供應量、各自購電量、節電量、年度與累計電費差額。

替代 PCS 效率預設沿用專案 PCS 效率（目前98%）；在比較區可獨立調整。節省每度電價值預設0.67 CNY/kWh，可調整。這兩項規劃假設只影響效率收益，不需要重跑物理測算。AC/DC充電機95.35%仍屬既有AC支路，與此PCS參數分開。

原全站售電收入、電量費與能源後貢獻仍保留在年度營運表。共同背景用電、既有AC支路與服務收入不混入效率收益。負值代表SST需要多付電費；缺少測算或不支援的設定留空，不以0代替。沒有任何年度資料缺口時，才提供完整十年累計。

## 共同邊界與公式

- SST方案：10 kV → SST → 公共DC母線 → 原DC/DC → 相同DC交付量。
- 替代方案：10 kV → 箱變 → PCS → 同一DC母線 → 原DC/DC → 相同DC交付量。
- 替代設備假設容量足夠；這是效率比較，沒有把負載搬到既有AC支路，也不宣稱替代PCS已完成容量／排隊驗算。
- 替代箱變沿用對應SST所在區的箱變效率（含個別設備覆寫）。跨區支援按實際SST來源輸出加權，不按受電區錯配箱變。
- 實際三日模擬的SST購電為 I_s、SST母線輸出為 O_s，兩側DC/DC群總輸出為 Q。對每個SST來源，替代購電 = O_s / (對應箱變效率 × PCS效率)，各來源加總為 I_p。
- 兩路徑效率：η_s = Q / ΣI_s，η_p = Q / ΣI_p。相同下游效率在兩方案都保留。
- 年度比較交付 D 沿用原庫存調整後DC供應量；兩方案購電分別 D/η_s 與 D/η_p。年度節電 = D/η_p − D/η_s；收益差額 = 年度節電 × 固定每度電價值。逐年按原始精度累加，僅顯示時四捨五入。
- D=0且模型支援時，節電與差額為0；有需求但沒有可信能量流則留空。
- 非設備組裝模式，或啟用儲能、光伏、備援、線損／效率曲線／變壓器非線性模型／補償模型時，簡化比較停用。原全站測算仍照常工作。
- 未計共同背景用電、容量費、設備投資、維運、稅務與逐時調度改變，不能稱為完整淨利或投資回收。

## 設定與匯出

新增可選 `loadPlan.pcsReferenceEfficiency`，合法值(0,1]。舊JSON沒有此欄位時回退專案PCS效率。容量快照忽略規劃欄位，但設備與劇本變更照常使結果失效。

十年CSV與估算JSON使用目前畫面參數；JSON格式升至2。新增每列比較依據、PCS效率、每度電價值、SST與PCS購電量及累計節省電費。旧 `acReferenceEfficiency` 更名為 `pcsReferenceEfficiency`，意義也隨替代方案更新。

結果XLSX仍是上次測算快照，不擅自覆寫其參數。Ten_Year_Settings與Ten_Year_Estimate增加相同比較假設與結果；若需最新規劃設定，先執行測算，或使用十年頁當前CSV／JSON匯出。
