# 經濟模型 — 0.3.0

受限模擬的每筆交易到站單價鎖定。kWh與單價各HALF_UP六位小數，交易累計金額HALF_UP到分；逐時收入取累計增量。購電按實際來源電表／小時先結算再以最大餘數法分攤至用電站與固定輔助。SOURCE_REPLAY只保留來源算術。測試政策不等於真實供電合同，月帳期、需量與稅須另校準。

以BigInt實作十進位結算；每票與合計上限10^12分=100億CNY，超限拒絕。獨立比對金額容差0分，未取整的解析金額另行保存，不能把兩者混算。

財務只使用不可變結果快照。多日期間合計先除以horizonDays，再依每年營運日外推。需求爬坡作用於收入、服務用電、其他變動費；固定輔助用電及固定OPEX照營運日計。月1是第一個爬坡月末，月0對應startLoad。

期末電池能源少於期初0.01kWh以上，停止NPV／IRR外推，不以平均購價或效率虛構補庫成本；保留明示的當期能源後貢獻。CAPEX或固定成本缺失也不產生投資回報。現金流假設交付即收款，未建應收、存貨會計、稅、折舊、資產替換或完整融資。

IRR使用縮放穩定多項式、有限根區間、前後零期修剪與正規化殘差≤1e-10。多符號變化保守標不可用，無根、極端不可表達值亦不假造IRR。年化=(1+月IRR)^12−1；折現率反向換月。NPV與現金流超出有限數值範圍不輸出結果。

收入−電費為能源後貢獻；再扣所填OPEX只稱模型營運貢獻，不稱會計淨利。正式基準、逐項測試與用途限制見VERIFICATION.md。
