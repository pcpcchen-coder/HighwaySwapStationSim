# 連續站務模型 — 0.3.0

Schema1.3以day+hour定位需求，horizonDays1–31。時間為期間起點後絕對分鐘。只在期間初始建立滿readySOC庫存；跨日保留排隊、預留電池、換電剩餘工時及充電進度。

每步在下一整分鐘、到站、設備狀態變更、換電完成、電池ready、EV充滿中取最早事件；用實際時長積分功率。換電需相容SOC窗口、ready電池、可用工位與必要輔助電源；失去電源會暫停，恢复后继续剩餘工作。零輔助只允許作为明示理想測試。

完成次數依[h,h+1)半開區間，最終期間終點歸最後一格。日末在新一期到站／開始事件之前取庫存／排隊狀態。每筆服務到站單價鎖定，充電交付與收入按實际交付区间逐步歸屬，完工數按完成時間計。

期末未完成服務的已交付部分計入電量與结算；未交付需求保留。不相容換電請求留隊並警示，不能阻塞相容請求。詳細設備案例用獨立rack/gun ID，關閉元件不供能，SST或站務輔助不足的相依功能停機。

每站每小時：grid − loss − auxiliary − delivered − Δstored = 0；跨站由source meter保留真實來源。精確的驗收、案例、前後缺口與尚未實測範圍見VERIFICATION.md。
