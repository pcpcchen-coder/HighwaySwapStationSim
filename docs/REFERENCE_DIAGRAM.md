# 原圖對照排列（2026-09-10）

供電設計與能量流驗算共用 `packages/reference-layout` 的位置、分區與正交走線。依使用者提供的雙服務區截圖，A 站在左，B 站鏡像在右，交流接入／箱變／SST／PCS 在上，兩條直流母線橫跨中央，乘用車站位於兩端，重卡換電站與外接槍在兩側下方，獨立超充堆靠內，儲能／光伏在中央，UPS／ATS 在上方供電區。

## 操作順序

1. 開啟「供電設計」，預設使用「依原圖排列」。先用「全圖」核對分區，再放大查看單台 DD、電池艙、雙槍終端與每支槍。
2. 點選節點查看名稱、ID、參數與啟用狀態。灰虛線是停用／預留，不能當作已啟用的供電。
3. 圖面排列本身不改電氣參數。若要保存原圖位置，點「套用原圖位置」；拖曳或方向鍵移動也會套用目前可見位置並切到「依設計位置」。
4. 匯出專案 JSON，或在重新測算後匯出 XLSX，保存已套用的位置。只切換觀看方式不會寫入專案。
5. 變更供電設計、設備或需求後重新測算，再到「能量流驗算」。它預設也用「依原圖排列」，元件位置與設計圖一致。
6. 使用「A 區供電／B 區供電」、放大、搜尋與「定位所選」逐節點核對。時間軸仍取同次成功測算快照，當下／每小時／累計模式均保留。
7. 要對照自己拖曳的位置，兩頁均切到「依設計位置」。驗算頁讀的是上一次成功測算的位置快照，須重算才會同步新的手動位置。

## 完整性與語義

- 完整預設為 148 個節點、166 條連線，每個都保留獨立 ID；16 個重卡電池艙、24 支槍沒有合併成假單一設備。
- 分區框與母線說明是呈現標記，不是額外能源來源、設備或導線。所有實際線段均來自原有 edge。
- 跨站雙向路徑仍是四個獨立有向電纜節點，使用分離走線；沒有把它們改成無限制雙向共母線。
- 交叉线不代表接點。端口連線仍以原有 source / target 為準。
- 截圖是一張概略單線圖，系統另展開進線／計量／負荷開關、DD、共享組與儲能充放電端，因此節點多於原圖圖示數量。
- 未啟用乘用車完整站務時，CATL 站保持交流負載節點；不因換了排列就假稱完整營運已啟用。
- 自訂或未識別的節點保留於下方延伸區，不隱藏、不刪除。
